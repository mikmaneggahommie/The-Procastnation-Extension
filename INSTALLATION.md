# 📦 How to Install the Cure Procrastination Extension

## Quick Installation Steps

1. **Open Chrome Extensions Page**
   - Open Google Chrome
   - Type `chrome://extensions/` in the address bar and press Enter
   - OR click the three dots menu → More Tools → Extensions

2. **Enable Developer Mode**
   - Look for the **"Developer mode"** toggle in the top-right corner
   - Turn it **ON** (it should turn blue)

3. **Load the Extension**
   - Click the **"Load unpacked"** button (appears after enabling Developer mode)
   - A file picker will open
   - Navigate to: `/Users/mac2015/Desktop/The Procastnation Extension`
   - Click **"Select"** or **"Open"**

4. **Verify Installation**
   - The extension should now appear in your extensions list
   - You should see:
     - ⚡ **Cure Procrastination** extension card
     - Version: **1.0.1**
     - Description: "Lock away temptation. Earn access through effort."
   - A lightning bolt icon should appear in your Chrome toolbar

5. **Pin the Extension** (Optional but recommended)
   - Click the puzzle piece icon in Chrome's toolbar
   - Find "Cure Procrastination"
   - Click the pin icon to keep it visible

## Testing the Extension

### Test 1: Visit a Blocked Site

Try visiting any of these default blocked sites:

- `youtube.com`
- `facebook.com`
- `twitter.com`
- `instagram.com`
- `reddit.com`

You should see a beautiful purple overlay with a stoic quote and countdown timer!

### Test 2: Configure Settings

- Click the extension icon in your toolbar
- A popup will appear with settings
- Try adding a new blocked site (e.g., `news.ycombinator.com`)
- Click "Save Settings"

### Test 3: Quick Test of Hard Lock

To test the hard lock feature quickly:

1. Click the extension icon
2. Change "Session Limit" to **1** minute
3. Click "Save Settings"
4. Visit `youtube.com`
5. Wait through the breathing room countdown and click "Continue"
6. After 1 minute, you'll see the type-to-unlock overlay!

## Troubleshooting

### Extension Not Loading?

- Make sure you selected the **folder** `/Users/mac2015/Desktop/The Procastnation Extension`, not an individual file
- Check that Developer Mode is enabled
- Try clicking "Refresh" on the extension card if you see errors

### Extension Not Working on a Site?

- Make sure the site is in your blocklist (check settings)
- Make sure the site is NOT in your whitelist
- Try reloading the webpage

### Timer Not Showing?

- Check if the breathing room was dismissed (click "Continue to site")
- Look in the top-right corner of the page
- Try reloading the extension (chrome://extensions/ → click refresh icon)

## Need to Remove It?

1. Go to `chrome://extensions/`
2. Find "Cure Procrastination"
3. Click **"Remove"**
